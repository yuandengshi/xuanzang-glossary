## 编号与缩略语

| 写法 | 说明 |
|---|---|
| T220 | 大正新修大藏经编号；T310-12 指 T310《大宝积经》第十二会 |
| K0016 | CBETA 所收高丽藏编号（648 年单译的《能断金刚经》） |
| To.16 | 德格版藏文大藏经《东北目录》编号 |
| 梵名 | 据 Lancaster《高丽大藏经解题目录》，点击可到该条目；经核查有误的已在备注中注明 |
| 公元 | 据《开元录》夹注所记年号换算，只算年份，不细算月日 |
| 同本异译 | 后出的译本注"后出"；"部分"指只有部分内容相当 |
| 部 · 卷 | 状况筛选按钮上的部数与卷数合计 |
