# 玄奘译语词汇表 体例草案（试点用，待定稿；2026-10-29 据用户意见修订）

## 一、数据的两层

1. **对应实例**：一个梵文词语与玄奘译语在某一处的对应，是最小的数据单位，每条都可回查。
2. **词条**：按梵文词目汇总所有实例，列出玄奘的各种译法、频次、出处和例句，附真谛译与唐代自注。词条由脚本从实例层自动生成，不手工编写。

## 二、对应实例的字段

| 字段 | 说明 |
|---|---|
| oid | 实例编号，如 `U01-003` |
| sid | 梵文句编号（对应 Pradhan 页行，由脚本换算） |
| skt | 梵文原形，与 GRETIL 本拼写完全一致（连声照录）。遇元音连声（如 hata + andhakāra → hatāndhakāra）时，取包含该词的最短连写片段，如 `āndhakāraḥ`；GRETIL 本的明显误字照录，在 note 中注出正读 |
| lemma | 词目：名词、形容词取词干；动词取词根并标前缀，如 `ud-hṛ`；复合词用连字符分出成分，如 `sarvathā-sarva-hata-andhakāra`。连字符只用于真正的复合词，两个独立的词（如 akliṣṭam ajñānam）分立两条。语法形式以词尾、后缀或句式立目，如 `-āt (abl.)`、`-sya- (fut.)`、`santi … yeṣām` |
| pos | 缩略语的全称和说明见词汇表页面的"缩略语"页。该词本身的词类：n. / adj. / pron. / ind. / num. / v. / ptc. / gdv. / abs. / inf. / cpd.；语法形式记 gram.。可附该处的格、数、时态，如 `n. gen.`、`v. fut. 1sg.` |
| xz_line | 玄奘译语所在的大正藏行（T29 页栏行，如 `0001a08`） |
| xz | 玄奘译语，与 CBETA 文本一致；不连续的用"…"隔开，如 `拔…出`。只取与该梵文词对应的部分，见第五节 |
| type | 对应类型，见下 |
| pm_line / pm | 真谛译的对应译语及其行号（能确定时才填） |
| note | 说明 |

## 三、对应类型

- **对译**：固定的、逐词的对当，如 abhidharma → 對法、pratipakṣa → 對治。
- **意译**：按意思改写，不逐词对当，如 māhātmya → 其體尊高。
- **音译**：如 abhidharma → 阿毘達磨。
- **拆译**：一个梵文词拆成两个以上的汉语成分，如 pratibandha → 覆…障、pratisaṃkhyāna → 各別簡擇。
- **合译**：两个以上的梵文词合成一个汉语译语，如 arthataḥ yathāpradhānam → 勝義（各词分别记录，note 注明"合为某某"）。
- **增译**：玄奘译文有、梵文没有的成分。skt 字段空着，note 说明增加了什么，如"唯"。
- **省译**：梵文有、玄奘没有译出的成分。xz 字段空着。
- **梵本缺文**：两个汉译（玄奘、真谛）都有、现存梵本（GRETIL/Pradhan）没有的成句或成词的内容，疑二人所据梵本有之，不算玄奘增译。skt 字段空着。只有玄奘有的仍记为增译；两个译者各自补出的连接字（謂、及、等）也仍记为增译。
- **语法**：用汉语虚词或句式对应梵文的语法形式，如第五格 -āt → 故、关系代词 yaḥ → 諸、kila → 傳說。

## 四、收词范围（全面词汇）

- 实词全收：名词、形容词、动词、分词、独立式、副词。
- 复合词：整个复合词立一条；成分词如果分开译出、译法值得注意，也各立一条。
- 虚词和语法形式：有对应汉语成分的收（如 hi → 以/由、ca → 及、iti → 故/名、tatra → 此中），没有对应成分的不收。
- 本颂与长行都收；本颂中为凑字数所作的变动，在 note 里注明。

## 五、译语的切分

**一词一条，译语只取与该梵文词本身对应的部分。** 由别的词或语法形式表达的成分不算在内，各自另立记录：

| 成分 | 归属 | 例 |
|---|---|---|
| 否定（不、非、無） | 归否定词 na、a-/an- 等 | nānuśerate：na → 不，anu-śī → 隨增 |
| 人称、时态（我、當、欲） | 归语法形式 | pravakṣyāmi：pra-vac → 說，`-sya- (fut.)` → 當，`-mi (1sg.)` → 我 |
| 完成、先行（已） | 归分词、独立式词尾 | uktaḥ：vac → 釋，`-ta (ppp.)` → 已 |
| 使役（令） | 归 `-aya- (caus.)` | bhramayanti：bhram → 漂轉，caus. → 令 |
| 复数（諸） | 归复数词尾 | dharmān：dharma → 法，pl. → 諸 |
| 抽象后缀、格（是、故、由） | 归 `-tva`、`-āt (abl.)` 等 | jagadāsaṅgasthānatvāt：…→ 眾生沈溺處，-tva → 是 |
| 被修饰的中心词 | 归中心词 | bhāvanāmayī prajñā：bhāvanā-maya → 修，prajñā → 慧 |
| 玄奘增出的字 | 记为增译 | 證不生法：證 |

- **动词词条只记词汇义**：词根没有人称和时态，时态、人称、语态、使役等形式的对应一律记在"语法形式对应"里。
- **动词单独切分**，不并入名词，如 abhidharma ity ucyate：abhidharma → 阿毘達磨，ucyate → 得名。
- **固定说法整体立条**，因为汉译本身是成套对应的，如 kiṃ kāraṇam → 所以者何、kiṃ tarhi → 云何／但、tathā hi → 所以者何…由。
- 代词还原为所指的（tasmai → 如理師），记为意译，note 注明。

## 六、虚词的收录

虚词全收，**每种对应只收一两例**；某个虚词在某处没有译出的，也收一例省译。例：ca → 及（两例）、ca →（未译，一例）；iti → 謂、名、名曰、名為、故、故稱、言、者、是名、如此（各一两例）。

## 七、合并时统一的写法（2026-10-29）

- **语法形式按范畴立目**：同一范畴的不同词尾并为一条，原词尾保留在 pos 里。例如 -āt、-tas、-ebhyaḥ 都立为 `abl.`；-tvā、-ya、-tya 都立为 `abs.`；-ya、-tavya、-anīya 都立为 `gdv.`。复数词尾对作"諸""眾"的立为 `pl.`，对作别的汉字的归各自的格。
- **实词词目**：否定前缀加连字符（a-bhāva、an-anta）；复合词成分一律用词干（cakṣus-、manas-），合写的 manovijñāna 拆为 manas-vijñāna。比较级写作 compar.。
- **虚词表**（"每种对应一两例"适用的词）：ca、vā、api、eva、iti、tu、hi、na、punar、tarhi、atha、athavā、kila、khalu、tāvat、yathā、tathā、evam、iva、atas、tatas、yatas、tatra、atra、yatra、iha、yadi、cet、yadā、tadā、kati、yāvat、nanu、kāmam、yasmāt、tasmāt、kadācit，各代词（tad、etad、idam、adas、yad、kim、katama、kaścit、kiṃcit），āha，以及固定说法（kiṃ tarhi、kiṃ kāraṇam、tathā hi、api tu、evaṃ tarhi 等）。anya、sva、pūrvam、ubhayatra、apara、yathākramam 等有实在词义、译法有变化的，按实词处理，每次出现都收。
- **全局裁剪**：按单位顺序，每个（词目, 译语）只留前两例，省译每个词目留一例；多出的移入 `_work/align/akbh1/occ_extra/` 存档，不删除。标"待核"的一律保留。
- **增字拆出**：note 中注明"X为增字/补出"、X 又在译语里的，把 X 拆为单独的增译记录。

## 八、核验

脚本逐条检查：skt 必须在 sid 所指的梵文句中出现；xz 必须出现在 xz_line 那一行，跨行时检查该行加下一行（不连续译语的每一段分别检查）；pm 同理。核验不通过的记录不进入词条。
